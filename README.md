#  Customer Churn Executive Dashboard (Tableau)

##  Overview
This project focuses on analyzing customer churn using Tableau. The dashboard provides a clear view of churn trends, revenue impact, and customer segmentation.

##  Objectives
- Analyze churn rate and active customers
- Identify revenue at risk
- Understand customer behavior across demographics and services

##  Files Included
- Tableau Dashboard (.twbx)
- Dataset (.csv)
- Project Report (.pdf)
- Dashboard Screenshot

##  Tools Used
- Tableau Desktop
- Excel / CSV Dataset

##  Key Insights
- Higher churn observed in short-tenure customers
- Contract type significantly impacts churn behavior
- Revenue loss is concentrated in specific customer segments

##  How to Use
1. Download the `.twbx` file
2. Open in Tableau Desktop
3. Interact with filters and charts
